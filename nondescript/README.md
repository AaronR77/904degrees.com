# 904° Nondescript Door — MARK11.1

The homepage Door link first fractures the visible page into falling square sections, then loads `/nondescript/`. A direct link skips the fracture and starts at the terminal.

The terminal displays theatrical, **non-executing** C#-like text. The decision is visual only. `Y` flashes lime/black twice and shows only `< Hello World >` for 3.5 seconds; `N` or two minutes of inactivity displays the normalcy message, a prompt, then routes to `/portal/`.

No audio, data collection, authorization logic, external scripts, or authentication changes. Users can skip to Portal, and reduced-motion preferences omit fracture and flashes.

The `/portal/` target continues to use the existing authentication and security configuration when deployed. Local Python serving does **not** enforce Cloudflare Access.
